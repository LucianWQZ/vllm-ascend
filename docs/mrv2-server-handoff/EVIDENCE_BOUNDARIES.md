# Evidence Boundaries

- Only Draft read table/length may change; canonical full write/slot/position and Target remain absolute/full.
- Host tests do not prove NPU Graph correctness.
- Diagnostic serialization does not prove normal overlapping reuse.
- Python/operator pointers do not prove task-internal operand binding or physical memory read-set.
- Target4 is a separate diagnostic capture profile and does not enlarge Base capture inventory.
- Old-SHA/device evidence is historical reference, not current-SHA acceptance.
- A parsed plan or CLI matrix is not an executed campaign.
